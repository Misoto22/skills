# Published skills

Only release-ready, recursively discoverable skills belong in this directory.

- [bazi-chart](bazi-chart/SKILL.md) — computes one reusable chart as canonical JSON and data-only Markdown.
- [bazi-reading](bazi-reading/SKILL.md) — interprets a completed single-person chart as an evidence-linked static natal report.
- [bazi-compatibility](bazi-compatibility/SKILL.md) — compares two reusable charts with transparent directional evidence and scores.
- [bazi-compatibility-reading](bazi-compatibility-reading/SKILL.md) — interprets a completed comparison without changing its source data or model results.

Shared calendar, chart, schema, and score rules are vendored into every skill by
the repository sync process.
