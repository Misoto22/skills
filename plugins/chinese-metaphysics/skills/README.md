# Published skills

Only release-ready, recursively discoverable skills belong in this directory.

- [bazi-chart](bazi-chart/SKILL.md) — computes one reusable chart as canonical JSON and data-only Markdown.
- [bazi-reading](bazi-reading/SKILL.md) — interprets a completed single-person chart as a reader-first natal report with a separate audit artifact.
- [bazi-compatibility](bazi-compatibility/SKILL.md) — compares two reusable charts with transparent directional evidence and scores.
- [bazi-compatibility-reading](bazi-compatibility-reading/SKILL.md) — interprets a completed comparison as a reader report with separate evidence, without changing its source data or model results.
- [ziwei-chart](ziwei-chart/SKILL.md) — places one twelve-palace Zi Wei chart as canonical JSON and data-only Markdown, and refuses to run without a stated gender.
- [ziwei-reading](ziwei-reading/SKILL.md) — interprets a placed Zi Wei chart as a reader-first report with a separate audit artifact, and an ink-wash poster only when asked.
- [bazi-ziwei-cross](bazi-ziwei-cross/SKILL.md) — reads one person's BaZi and Zi Wei charts against each other, recording contradictions instead of averaging them into a score.

Shared calendar, chart, schema, and score rules are vendored into every skill by
the repository sync process.
