# BaZi Compatibility Reading

Read completed comparison data and write `bazi_compatibility_reading_<name-a>_<name-b>.md` without changing either source chart or score.

## Boundary

- Require both source identities, all five dimension ledgers, weights, scores, confidence, and sensitivity.
- Preserve direction and asymmetry rather than flattening both experiences into one claim.
- Never infer romance, marriage, friendship, family, or work when the request did not state it.
- Describe scores as outputs of the named model, not probabilities or objective truth.

The full evidence weighting, bilingual report structure, validation rules, and examples are added with the reading implementation.
