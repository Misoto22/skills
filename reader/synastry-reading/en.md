`synastry-reading` reads a synastry file that has already been computed. It performs no astronomical calculation of its own.

## Every judgement links back to specific aspects

The output is a Markdown report in which each judgement links back to the aspect data in the file. You can see which aspects a conclusion was drawn from, rather than reading a description with nothing to check it against.

The format constrains the writer as much as it serves the reader: a judgement with no aspect behind it has nowhere to sit.

## Uncertainty changes the wording

It reads the uncertainty recorded in the file and adjusts accordingly. Where the birth time is a window, the parts of the reading that rest on the ascendant and the houses are stated with correspondingly less certainty instead of being written flat.

## What it does not do

It does not calculate — that is `synastry`. It does not read the legacy TXT format, does not accept raw birth details, does not compute a single-person natal chart, and produces no transits, forecasts, or compatibility score.
