# Brand assets

`hero-light.png` is the light-theme README Hero for the English and Simplified
Chinese READMEs. It uses a rice-paper ivory surface with mist, moss, cypress,
and ink tones.

`hero-dark.png` is its dark-theme counterpart. It preserves the approved
composition and wordmark while using charcoal-cypress, deep forest green, muted
sage, and warm rice-paper ivory for contrast.

Both assets contain the exact wordmark `skills`, a single leaf, and a subtle
water-ripple motif. They are selected through the README `<picture>` elements
using `prefers-color-scheme`.
